# Implementation Plan: Fix JSON Output Corruption

**Branch**: `004-fix-json-output` | **Date**: 2026-08-03 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/004-fix-json-output/spec.md`

## Summary

Every `--format json` code path in the CLI calls `console.print(json.dumps(...))`, which passes a JSON string through Rich's markup parser. Rich interprets `[` and `]` in JSON arrays as markup tags, producing interleaved warning messages and potentially corrupted output. The fix is a surgical substitution: replace every `console.print(json.dumps(...))` call with `click.echo(json.dumps(...))`, which writes directly to stdout without markup processing. `click.echo` is already a project dependency (via Click) and is already used correctly in the `ndjson` output path.
